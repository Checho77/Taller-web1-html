# CV Web - Sergio David Castro Galindo

Este es mi proyecto para el Parcial I de Programación en Ambiente Web I,
con el profe Jesus David Mejia Vergara. Es una hoja de vida hecha con
HTML5, CSS3 y PicoCSS.

## Tecnologías

- HTML5
- CSS3
- PicoCSS (https://picocss.com/), lo usé como base para no tener que
  armar todo el diseño desde cero y poder enfocarme en el contenido y
  en los ajustes propios

## Cómo está organizado

```
Parcial1-CV/
├── index.html
├── css/
│   └── style.css
└── README.md
```

## Qué incluye

La página tiene las secciones que pidió el parcial: información
personal, perfil profesional, formación académica, experiencia,
habilidades, proyectos, cursos y certificaciones, y contacto.
